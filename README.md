# نظام سهيل المحاسبي المتكامل
## Suhail Accounting System

تطبيق نظام محاسبي متكامل مبني بـ TypeScript و React

### المميزات
- 📊 لوحة تحكم شاملة
- 💰 إدارة الحسابات المالية
- 📦 إدارة المخزون والمنتجات
- 🛒 نظام نقاط البيع (POS)
- 📈 التقارير والتحليلات
- 🔐 نظام أمان متقدم
- 📱 واجهة سهلة الاستخدام

### البدء
```bash
npm install
npm run dev
```

### البناء
```bash
npm run build
```

### الهيكل
```
src/
├── components/    # مكونات React
├── contexts/      # Context API
├── lib/           # مكتبات وأدوات
├── styles/        # التصميمات
└── App.tsx        # التطبيق الرئيسي

database/
└── migrations/    # ملفات قاعدة البيانات
```

### المتطلبات
- Node.js 16+
- npm أو yarn
- Supabase account
